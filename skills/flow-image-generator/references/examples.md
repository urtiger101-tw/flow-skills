# Flow 圖片提示詞範例

將方括號改成任務內容，並在 UI 另行設定比例、輸出數和模型。範例是可修改的草稿，沒有實際送出生成。

## 1. 獨立圖片：歷史頻道封面

```text
製作一張 16:9 的歷史影片封面：明代宮殿屋脊與雨後石板廣場，清晨薄霧，遠景有一位身穿明代服飾的人物背影。電影感寫實攝影，低角度廣角構圖，主體放在右三分之一，左側保留乾淨空間供後製標題。冷藍環境光與溫暖晨光，建築細節可信，不加任何文字、浮水印或現代物件。
```

檢查：比例、留白、服飾與建築細節；若用途是 9:16 Shorts，重新設定比例並調整構圖，不能只裁切人物。

## 2. 參考圖編修

前提：使用者已提供或指定要編輯的圖片。

```text
保留參考圖中人物的臉部特徵、服裝與站姿。只把背景改成雨夜的台北街道，路面有柔和倒影，鏡頭角度與人物比例維持不變。自然寫實光影；不要新增其他人物、招牌文字或改變原有表情。
```

檢查：原人物身份特徵仍一致，改動僅限指定區域；保存原圖與編修後圖片的不同檔案。
